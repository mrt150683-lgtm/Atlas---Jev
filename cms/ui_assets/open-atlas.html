ATLAS

Start Atlas to open your project

This file contains the interface. Atlas needs its local server to read your project and display its map.

  1. Go back to the Atlas project folder and double-click CMS.bat. For a packaged copy, open CMS.exe.
  2. Keep the Atlas window open. It opens the working interface in your browser when ready.
  3. If the source launcher reports a missing runtime, double-click Setup-Atlas.bat, then try CMS.bat again. Setup requires Python 3.11 or newer and internet access.

Open the local Atlas app
